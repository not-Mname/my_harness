# 持续轻量流程

将当前对话切换为持续轻量模式，而不是只覆盖当前任务。

1. 读取 `~/.codex/rules/workflow-modes.md`。
2. 将当前对话的持续模式记录为轻量，直到用户显式调用 `$workflow-full`、使用 `[模式：完整]`，或开始新对话。
3. 调用消息包含任务正文时，切换后立即按轻量流程执行该任务；后续任务继续使用轻量流程。
4. 调用消息没有任务正文时，只确认“已切换为持续轻量流程”，随后停止。
5. 不把本次调用解释为临时覆盖，不恢复调用前的模式。
6. 无法安全地轻量完成时，按流程模式规则进入 HITL；不得静默升级或绕过始终生效的安全规则。
