# 持续完整流程

将当前对话切换为持续完整模式，而不是只覆盖当前任务。

1. 读取 `~/.codex/rules/workflow-modes.md`。
2. 将当前对话的持续模式记录为完整，直到用户显式调用 `$workflow-light`、使用 `[模式：轻量]`，或开始新对话。
3. 调用消息包含任务正文时，切换后立即按完整流程执行该任务；后续任务继续使用完整流程。
4. 调用消息没有任务正文时，只确认“已切换为持续完整流程”，随后停止。
5. 不把本次调用解释为临时覆盖，不恢复调用前的模式。
6. 完整表示执行全部适用流程，不机械调用无关 Skill，也不得绕过始终生效的安全规则。
